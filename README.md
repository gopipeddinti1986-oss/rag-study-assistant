# 📚 RAG Study Assistant

AI-powered PDF Question Answering System built using React, FastAPI, LangChain, ChromaDB, and Groq.

---

## Features
- Upload PDF
- Ask questions about PDF
- AI-powered answers
- Vector search
- Modern React UI

---

## Tech Stack
Frontend
- React
- Vite
- Tailwind CSS

Backend
- FastAPI
- Python

AI
- LangChain
- ChromaDB
- Groq
- Sentence Transformers
