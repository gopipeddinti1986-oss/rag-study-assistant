# Sprint 1 – PDF Upload Service

## Sprint Goal

Build a backend service that accepts a PDF upload, stores it locally, extracts text using PyMuPDF, and returns the extracted data as JSON.

## Tasks Completed

- Created FastAPI project
- Implemented GET /
- Implemented POST /upload
- Saved uploaded PDF
- Extracted PDF text using PyMuPDF
- Returned JSON response
- Tested using Swagger UI

## Technologies Used

- FastAPI
- Uvicorn
- Python
- PyMuPDF
- Swagger UI

## Challenges

- Installing python-multipart
- Understanding UploadFile
- Learning PyMuPDF

## Outcome

Successfully built and tested a working PDF upload service capable of extracting text from uploaded PDF documents.
